# scraper — демо-парсер сайтов в Excel

CLI-инструмент для портфолио: собирает записи с сайта-каталога (наименование, ссылка,
цена, мета) и складывает в готовый Excel-файл с двумя листами — «Данные» и «Сводка».
Без headless-браузеров: чистые `requests` + `beautifulsoup4`, вывод через `openpyxl`.

## Быстрый старт

```bash
pip install requests beautifulsoup4 openpyxl

# Офлайн-демо (ничего не скачивает, работает всегда):
python run.py --source demo --out demo_result.xlsx --limit 8 --json demo_result.json

# Живой источник — открытый учебный каталог книг:
python run.py --source books --out result.xlsx --limit 5
```

## Источники

| Значение `--source`            | Что это |
|--------------------------------|---------|
| `demo`                         | Локальный демо-каталог книг (`data/demo_catalog.html`), работает без интернета |
| `books`                        | https://books.toscrape.com/ — открытый каталог, созданный специально для практики парсинга |
| `https://...` (любой URL)      | Прямая ссылка на страницу; сперва пробуются карточки каталога, затем общий разбор заголовков и списков |
| путь к `.html` файлу           | Разбор локального файла (удобно для отладки селекторов) |

## Флаги

| Флаг | Назначение |
|------|-----------|
| `--source` (обязателен) | Пресет, URL или путь к HTML-файлу |
| `--out FILE`            | Куда сохранить Excel (по умолчанию `result.xlsx`) |
| `--limit N`             | Взять первые N записей — быстрый прогон для проверки |
| `--json FILE`           | Дополнительно сохранить те же записи в JSON |
| `--timeout SEC`         | Таймаут сети (по умолчанию 20 сек, можно задать в `config.py`) |

## Что внутри Excel

- **Лист «Данные»** — таблица: №, Наименование, Ссылка (кликабельная), Цена (число),
  Мета (наличие, рейтинг — что источник отдал).
- **Лист «Сводка»** — источник, дата, количество записей, уникальные наименования,
  сколько записей с ценой, min/max/средняя цена (или прочерк, если цен нет).

## Коды возврата

| Код | Значение |
|-----|----------|
| 0 | Успех (в том числе «источник не дал записей» — тогда Excel с нулями и предупреждение в консоли) |
| 2 | Источник недоступен: нет сети, таймаут, 404, другой HTTP-код, файл не найден |
| 1 | Прочие ошибки (некорректные аргументы, отказ в записи файла) |

Трейсбеки в консоль не сыпятся: все ошибки источников перехватываются и печатаются
одной понятной строкой в stderr.

## Конфигурация и секреты

Скопируйте `config.example.py` в `config.py` и при необходимости поменяйте
`USER_AGENT` и `TIMEOUT`. Токены и ключи — только в `config.py` (не коммитится)
или в переменных окружения. Без `config.py` всё работает на значениях по умолчанию.

## Как показать клиенту (2 минуты)

1. `python run.py --source demo --out demo_result.xlsx` — офлайн, ничего не сломается;
   открыть файл, показать листы «Данные» и «Сводка».
2. `python run.py --source books --limit 5` — показать, что то же самое тянет живой сайт.
3. Объяснить: для сайта заказчика меняется только разбор карточек (селекторы в
   `scraper_core.py`, функции `_catalog_records` / `_generic_records`) — выходной Excel
   и CLI остаются прежними. Готовые демо-файлы для показа лежат в `docs/`.

## Тесты

```bash
python -m unittest discover -s tests -v
```

Покрыто: разбор карточек по фикстуре, дедупликация, распознавание цен
(£/$/€/₽/руб.), общий разбор без карточек, запись и переоткрытие xlsx со сводкой.

## Демо-пакет в `docs/`

`demo_terminal.txt` (снимок вывода), `demo_table.txt` (содержимое xlsx в тексте),
`demo_result.xlsx` и `demo_result.json` генерируются реальным запуском программы:

```bash
python docs/make_demo.py
```

## Ограничения

- Не рендерит JavaScript: сайты, где данные подгружаются скриптами, не поддерживаются
  (для них нужен selenium/playwright — отдельная задача).
- Не обходят капчи и антибот-защиту — и не должны.
- При работе с любым сайтом уважайте robots.txt и не создавайте лишнюю нагрузку:
  используйте `--limit` при проверках.
